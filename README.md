# WebProject-Form-Validation-system
This is a JavaScript-based form validation project built using HTML, CSS with Bootstrap, and vanilla JavaScript. The form includes five required fields: Full Name, Email, Phone Number, Password, and Confirm Password. Each input is validated using JavaScript with clear error messages shown when the input is invalid.
